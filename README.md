# German & US Fixed-Income Mortgage Desk Analytics

🚀 **Live Dashboard:** [View Interactive Analytics App]([https://your-app-name.streamlit.app](https://german-us-fixed-income-mortgage-analytics-uacjwyd7s4mgzfmetcud.streamlit.app/))
An end-to-end financial data analytics project focused on
fixed-income and mortgage markets.

## Project Objective

The goal is to build a market analytics platform that combines:

- Financial data ingestion
- Data validation and transformation
- Quantitative analytics
- Risk and scenario analysis
- Interactive dashboards
- AI-assisted market research

The project is designed as a portfolio project for
financial-market, quantitative analytics, data and AI roles.

## Current Focus

Version 1 focuses on the German mortgage market using
public data from the Deutsche Bundesbank.

Current analysis includes:

- German mortgage interest rates
- Monthly rate changes
- Year-over-year changes
- Rolling averages
- Market trend visualization
